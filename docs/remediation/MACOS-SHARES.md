# 原生分享管理

文件工具栏和右键菜单可打开当前文件的分享，确认创建链接、指定有效期、可选提取码和下载次数上限；侧栏「分享」查看此账户创建的全部链接，并可显式复制或确认撤销。空间文件继续使用空间成员角色，不提供公开分享入口。读者是否仍可创建分享由服务器提交时重新鉴权，不在原生界面推定所有者专属规则。

默认创建配置为 24 小时、需要提取码、最多下载 10 次。小时数允许 0–8760，0 表示不自动到期；下载上限允许 0–1000000，0 表示不限。提取码是 6–72 字节可见 ASCII、不含空格，关闭保护后清空。确认显示实际解析的数字，避免 `00` 被误解为零小时到期。成功后只显示保护/到期/限制，链接在明确点击后写入剪贴板，提取码不进入链接、产品日志或持久会话。创建表单关闭后清除提取码和当前回执；剪贴板中的分享链接按用户复制意图保留，供另行发送。

创建回执须符合请求保护和次数、到期是否为空、分享码及本服务器相对访问路径；外站地址或静默降级被拒绝。每个授权记录绑定原账户，URL 由捕获的 HTTPS 服务器与安全分享码构造。列表最多接受 5000 项/4 MiB，异常、403 或重复记录清空旧能力行，替换请求取消旧响应，不能让旧 401 影响新会话。结果不明不自动创建或撤销重试，须先刷新核对；尚无持久幂等意图或服务器游标分页。

## 文件名与权限

`GET /api/shares` 在原字段外新增可空 `file_name`，不增加数据库列。单次查询仅关联当前可读取且未删除的文件；文件授权撤销后不再暴露其后来修改的新文件名，创建者仍能撤销自己的旧链接。原分享码、文件 ID、创建者、保护状态、次数与日期字段保持兼容。未提供名称的旧响应不推断文件仍可访问，实际读取/下载继续由服务端验证当前授权。

当前副本只完成原生创建/管理入口。链接沿用现有 HTTPS `/api/public/shares/:code` 协议；匿名提取码须使用 `X-Share-Passcode`，不放进 URL。公开接收链接的原生打开/流式下载界面仍在后续 G09 范围中，不能用下面的独立 HTTP 验收替代该界面。
