# 原生版本历史、下载与恢复

G08 将已有 Go 版本协议接入独立 macOS 客户端。普通文件的文件菜单、右键菜单和 Inspector 可打开版本历史窗口，显示版本号、当前标记、大小、创建时间、创建者及说明。文件夹不提供该入口。窗口支持刷新、原生保存面板下载所选版本，以及经确认后恢复为一个新版本；原有历史不被覆盖。

## 读取与恢复基线

此前 `GET /api/files/:id/versions` 仅返回 `items`。新增真实 API 回归首先得到 `file_id=0/current_version=0/rows=1`，证明响应没有可用于恢复确认的当前版本信息。响应现增加 `file_id` 和 `current_version`，保留原 `items` 及各行字段；旧客户端可继续忽略附加字段。新的仓储入口在同一只读 Repeatable Read 快照内读取活动文件、核对资源权限，再读取当前版本与历史，避免分别请求时拼接不同代次。

原生客户端校验文件 ID、非负当前版本、历史行 ID/版本号唯一性、版本范围和可选大小；响应最多 8 MiB，超限拒绝，不将部分历史显示为完整结果。此新功能需要提供附加字段的后端，不通过猜测最高历史行来兼容缺失的恢复基线。大规模历史的游标分页仍待后续处理。

确认框捕获选中的历史行和当时看到的 `base_version`。恢复请求仍调用已有 `POST /api/files/:id/versions/:version/restore`，由服务端在事务中检查当前版本、写权限、历史来源、内容和配额，追加新版本。客户端核对回执文件 ID 和新版本号，再刷新历史及原文件页。遇到 409 不自动换基线重试，清空旧列表并要求刷新后重新确认；连接/响应故障不声称事务已经回滚，而是提示先刷新核对结果。账号或服务器身份变化后，旧窗口状态不能继续读取/操作另一个身份的数据。

版本列表不使用 `storage_id` 发起发布，客户端也没有任意存储对象引用入口。专用安全版本上传票据和从本地文件发布新版本的完整界面仍待实现，本批不将 FILE-012 标为完成。

## 持久历史下载

历史下载走 `GET /api/files/:id/versions/:version/download`，接入现有分段读取、强 ETag/完整摘要、已确认前缀校验、暂停/重建/继续和原子发布。版本号与可选登记大小保存在任务记录中，后续当前文件发生变化不会更换下载路径。已有大小与首次强 ETag 被固定；历史响应若改变大小/身份则失败，保留原检查点，不改下载为当前文件。任务列表显示“历史版本 N”，完成后可在 Finder 显示实际保存文件。

历史任务使用新的持久 `direction=versionDownload`。仅增加可选字段会被旧二进制忽略，从而可能将任务当成当前文件下载，因此必须让旧枚举解码明确失败。普通上传/下载旧记录保持可读；含历史任务的目录不能交由旧客户端继续管理，应使用支持该类型的客户端。回归同时验证旧格式读取、新类型保留、旧枚举拒绝新记录，以及不合法版本/大小组合被拒绝。没有重写现有用户任务或删除历史记录。

## 已执行验证与边界

- Go 真实 API（本机 race 两项 4.847s）：正常/跨用户拒绝、读协作者可读取但不能恢复、撤销后拒绝；另一请求连续追加 16 次恢复时，每次读取的当前版本与全部历史仍来自同一快照。
- Swift 普通测试：22 项（需真实服务及 Keychain 的测试按开关跳过），包含历史大小/身份固定、检查点兼容/拒绝及不一致响应校验。
- 真实 Swift→TLS/Go/MySQL/Redis：9 MiB + 173 字节历史下载在 4 MiB 检查点暂停；队列关闭重建，另一窗口先把当前版本从 2 改为 3，历史下载继续取得原字节，当前下载仍得到不同的新内容。旧确认基线返回冲突且没有追加；刷新并重新确认后生成版本 4，再下载当前内容与原字节一致；跨用户拒绝和退出后清空状态通过。最后一轮约 10.121s；该新用例使用内存会话，没有访问旧钥匙串项目。
- Go 普通 race/vet/build、仓库及 diff 检查已执行通过。Swift 新测试初次有 async 调用和嵌套 Testing 宏编译错误，已按编译器错误拆开调用，保留原断言并重跑通过。
- 独立原生验收入口编译及签名通过；本机启动指定验收实例后，CUA 对该实例返回 `cgWindowNotFound`，未获得窗口，**版本窗口的交互/视觉验收未完成**。已核对 PID/路径后仅终止本次临时实例，停止独立服务，保留失败记录；没有借启动成功代替 GUI 验收。

本机可用 `CLOUDNEST_SWIFT_TEST_FILTER=realBackendVersionHistory python3 scripts/test-macos-backend.py` 定向运行新用例，依赖路径可用既有两个私有前缀环境变量覆盖。未提供 Swift 过滤变量时，CI 继续执行完整的串行真实后端 suite；受限账户仅执行其允许的会话用例。最终提交的 macOS 26/27 和完整后端 CI 单独按 SHA 核验。

本批是版本列表/下载/恢复的接入，不替代实际 GUI 验收、版本上传协议、极大历史分页、大文件资源基准或整个 G08/G00–G11 目标。
