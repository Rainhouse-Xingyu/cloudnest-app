# ZIP 源校验、临时预算与生命周期

2026-10-23–24，G03 / PR #4，代码完成待审。沿用已登记本机传输卷，未操作生产库或历史文件；G03、缓存治理和客户端恢复尚未验收完成。

## 行为与源内容

普通目录下载、批量下载、公开目录分享都先获得完整授权清单、读取租约和有效速率策略，再创建登记归档。每个普通对象从当前 scope 的固定 Pin 快照打开一次，检查普通文件/尺寸/有效 SHA-256，并通过 64 KiB 缓冲在复制进 ZIP 的同一遍读取中计算摘要。最多读取声明尺寸 + 1；单个源声明最多 1 TiB。缺失文件按既有 404；长度、摘要或旧 MD5 元数据不匹配为 409。任一项失败，整个私有归档废弃，不能给用户返回一个省略坏条目或包含坏字节的成功 ZIP；不修改源对象。

ZIP 继续使用 Go archive/zip 默认压缩，文件名避让、空目录及批量目录中的内嵌 ZIP 结构保持。内嵌 ZIP 直接写入外层 entry，**没有额外的内层磁盘临时包**。路径名/目录数沿用授权树的深度、条目数及 ZIP 名字长度检查；批量请求 JSON 连同尾随内容现最高 16 KiB，超限 413（不依赖 Content-Length），额外第二个 JSON 值 400，树/条目合计仍最多 10,000。16 KiB 的输入上限也可能先于条目数限制生效，客户端应分批选择。

全部条目成功、ZIP Close 成功后才 Sync/Seal。输出前对实际归档 FD 再验证完整尺寸/SHA-256，并 rewind 同 FD 交给统一限速发送，ETag/Repr-Digest 属于最终 ZIP 字节；即使路径被替换也不会重新打开另一个归档。已经收到 200/206 后仍须完整读取和最终校验，网络错误不追加 JSON。强 If-Range 的约定仍见 DOWNLOAD-INTEGRITY；每次请求重新构建归档，只有 ETag 相同才可追加原片段。

## 预算与准入

所有 ZIP 写入 DATA_DIR/storage/.archives-v1 下的随机私有 0600 登记文件，不再写系统临时目录。kind=archive、task_id=0、transfer_epoch=0 表示请求级派生对象，**不创建虚构的 UploadTask**；不将归档发布成用户存储对象。上传 chunk/merge 和归档使用同一个 transfer_volume 字节额度及 statfs 余量（默认保留 64 MiB），不是用户逻辑容量重复扣费。

创建先登记并收费至少 1 字节，再创建/锁 FD/持久化设备 inode。归档在写入触及预留前，以共享策略锁→请求者账本锁→卷行排他锁→登记行锁的顺序申请增长，提交后才允许该次实际 Write。按 1 MiB 量级增长，但接近剩余额度/空闲量时可缩到实际可用量；不会为了凑齐 1 MiB 而拒绝仍能容纳的写入。单归档输出最高 1 TiB（声明边界，未以 1 TiB 实测）。不假设压缩率，不改用无压缩格式来回避预算计算。

写入中全额预留保守计入 unwritten，可能比尚未写出的真实差额更大；Seal 后缩到实际归档尺寸，归档已占磁盘且在 HTTP 输出期间继续收费。并发增长串行检查卷额度与真实空闲，未知提交结果不执行未确认写入，持久预留继续保留。507 表示临时卷/余量不足，503 表示登记/策略/数据库不可用；失败时已写的私有字节也须经过正常对账才能释放收费。

共享活动归档上限每请求者 2、每卷 4，计入 intent/writing/ready；超限使用既有可重试 409/Retry-After: 1。公开分享使用**分享创建者**作为请求者，避免匿名请求绕开计数；仍按当前创建者权限授权每个条目，匿名速率沿用全局策略。这是活动归档准入，不是总请求/历史记录数量配额，也不提供公平队列。ZIP 构建从取得归档句柄后有十分钟可取消期限，该期限不包括元数据收集和 HTTP 输出，后二者仍未具有统一的总时限；普通磁盘系统调用不能由 Go 强制抢占，亦未将期限当作 CPU/IO 压测证据。

## 保留、续租与回收

归档沿用本机 Root/O_EXCL/FD 排他锁、90 秒 UTC 租约和 20 秒续约；续约不依赖不存在的上传任务。打开的句柄在构建、预校验、慢速 HTTP 发送全程持锁，过期记录也不能抢删正在使用的 FD。续约失败取消归档 context，限速等待/后续复制与响应停止；已送交网络/系统调用的字节不能撤回。

响应完成、条件响应或构建/发送失败后关闭句柄，再持久标记 discard，并交由同一受控 reconciler：完整元数据可见性/无未知触发器、根/真实数据库/卷身份、普通文件/设备 inode/容量及 storage/upload_chunk 引用审计→提交 deleting 与审计→unlink/目录 Sync→done 与释放额度/审计。进程崩溃关闭内核 FD 后，过期 archive 可在没有 UploadTask 的情况下受控恢复。不能凭文件名前缀接管旧路径。

半登记、替换路径、外部引用、未知结果和清理故障仍保留/收费；清理失败记录通用日志，后续 worker/CLI 可报告。普通成功下载不谎称所有清理已完成。批量业务审计仍记录成功输出；若正文已发送后审计失败，只记录错误，不能向 ZIP 加 JSON 或撤回网络字节。可靠审计 outbox 属 G06。
