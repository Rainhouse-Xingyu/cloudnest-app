# FRP 映射分配、并发写入与升级

映射 API 使用稳定的 `server_id` 划分资源：正值代表已登记的服务器，省略或零保留历史全局作用域。全局映射与所有服务器重叠；两个不同的正值服务器可以复用相同端口或域名。服务器端点别名仍可能指向同一实际 frps，当前不会自动识别。数据库中的预留也不证明远端端口已释放或隧道已注册；真实进程状态见 [注册诊断](FRP-AGENT-DIAGNOSTICS.md)。

## 写入协议

创建、修改、删除统一进入最多五秒的 READ COMMITTED 事务，锁顺序为 `frp_mapping_pool(id=1)` → 设备所有者 → 设备 → 映射。数据库行锁覆盖不同后端进程；运行时不创建缺失的锁行，也没有不加锁的回退路径。设备归属的首次读取只用于确定锁顺序，取得锁后重新核对归属和启用状态。旧所有者不能借助等待前的检查继续写入；禁用设备仍允许所有者删除映射。账号禁用时拒绝写入。

历史全局作用域的自动端口范围保持 20000–20999；正值服务器使用其当前策略的 TCP 范围。一次有界查询取已占用端口，选最小空位，插入和审计提交后才释放锁。历史固定端口仍支持 1–65535，托管 TCP 须在服务器策略范围内；禁用映射仍占用其端口。显式重复端口或域名返回 409，自动池耗尽返回 409。锁等待超时、死锁或缺失锁行返回 503，不自动重放写入。网络失联导致提交结果不明时，调用方应先查询映射列表再决定重试创建。

每次成功写入与 `frp_mapping_create/update/delete` 审计同事务。审计只含映射 ID、设备 ID、操作者及客户端 IP；失败全部回滚。修改响应取自该事务的结果，不在提交后重新查询可能被其他请求改写的记录。

创建/修改校验端口范围、状态只能为 0/1、域名长度和 DNS 标签；拒绝路径、端口后缀、用户信息、模板、域名内部控制字符、非法标签。明确传入 `status=0` 保持禁用，避免 GORM 的旧 `default:1` 标签把零值改成启用。

## 域名键

`cn_domain_key_v1` 是数据库生成列，`uq_frp_domain_v2(server_id, cn_domain_key_v1)` 是完整唯一索引。TCP 使用生成列 `cn_port_key_v2` 和完整唯一索引 `uq_frp_port_v2(server_id, cn_port_key_v2)`。正值服务器的 HTTP/HTTPS 映射使用 remote_port=0，其 TCP 键为 NULL，不占用无关 TCP 端口；历史作用域保留旧端口占用。空域名生成 NULL，允许多个 TCP 映射。HTTP 的裸域名与 `http://` 前缀共用一个键；大小写和末尾 DNS 点不产生不同预留。HTTPS 使用独立协议键，支持 HTTP/HTTPS 各自监听相同主机名。通配域名保留 FRP 原有语义，通配符与其覆盖的具体域名不是同一个键。

新写入将 HTTP 域名保存为小写裸主机名、HTTPS 保存为小写 `https://主机名`；历史 `domain` 原文不重写。数据库唯一索引约束同一 server_id 中的重复键；作用域 0 与正值作用域之间的重叠检查由持有共享池锁的应用事务执行，不能声称任意直接 SQL 也受这一跨作用域规则保护。自动分配的串行语义要求所有写实例升级；旧程序不持有池锁，不能混跑。

## 显式升级

1. 备份并停止旧后端写实例；在备份副本中演练。普通启动不修改结构。
2. 使用已有服务端 `migrate` 命令补齐旧版约束及默认零的 server_id；先安装运行资源账本并回填历史，再通过单个 MySQL ALTER 原子替换旧全局唯一索引为两组复合唯一索引、增加端口生成列。保留所有历史映射的 ID、原文和零作用域，不猜测服务器关联。存在未识别的历史非零关联时拒绝升级。
3. 若历史映射存在规范化后的重复域名，迁移失败，原有行保留。操作者必须先确认映射归属、在用配置和远端占用，再决定如何处置；迁移不自动选择“保留哪一条”。失败后可以重新执行。
4. 启动只读核对生成表达式、列类型/排序规则、完整唯一索引、InnoDB 表和池主键/锁行。缺失、篡改、部分结构都不能作为已完成升级。已有但不符合定义的对象不会被本迁移静默替换。

本批仍使用项目已有显式 `migrate` 流程，未宣称整个旧模型 AutoMigrate 已转为版本化迁移。生产数据、生产结构和真实 FRP 服务器均未操作。

## 托管映射 API

创建 `/api/frp/mappings` 可提供 `server_id`。服务器须启用且与设备同属一个用户，管理员也不能跨用户混用。TCP 省略 remote_port 时按当前服务器策略分配；HTTP/HTTPS 省略或显式为零，并要求相应虚拟主机端口已配置。非法输入返回 400，策略不允许/资源冲突返回 409。更新不接受 server_id，即使值未变；迁移到其他服务器须新建映射并按部署/清除协议处置原配置。

托管配置生成仅选择当前设备的作用域零及所选服务器的活动映射；旧原始端点配置入口只选择作用域零。元数据列表保留所有作用域。HTTP 转 TCP 且省略 remote_port 时分配新端口，TCP 转 HTTP 时清零；配置/运行账本中的旧资源继续保留。已停用服务器或策略已不允许原资源时，修改映射会被拒绝，所有者仍可删除映射，但删除不会释放运行占用。
