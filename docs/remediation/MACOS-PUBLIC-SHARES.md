# 原生分享接收端

登录页和分享管理页均可打开 HTTPS 分享链接。接收端不要求登录，先确认服务器来源再发送可选提取码，再读取文件资料。下载使用原生保存面板，提交前显示来源、名称、目标路径和可能计次的说明。关闭后清除内存中的链接、提取码和资料，不创建账户或持久分享能力记录。

## 协议与本地文件

仅接受完整 `/api/public/shares/:code`，拒绝 HTTP、URL 用户信息、查询、片段、编码路径混淆和额外路径。每个请求使用隔离的 URLSession；清除继承的 Authorization、Cookie、代理认证、缓存和凭据存储，不跟随重定向，不响应 HTTP 身份挑战。提取码仅进入 `X-Share-Passcode`。匿名 401/403 不影响已登录账户。

元数据上限 64 KiB，核对分享码、文件身份、大小、目录标志和期限。下载仅接受完整 200，须有相符的强 ETag、Repr-Digest、Content-Length 和 identity 编码；普通文件长度须等于确认的元数据，ZIP 至少 22 字节，最大 1 TiB。单块网络背压与磁盘写入有界，完成后从已打开文件重新计算 SHA-256，并同步后发布。私有 `.part` 为独占创建的 0600 常规文件，重名使用新名称，不覆盖既有目标，旧预览命名空间禁止写入。

不自动重试、续传或重放匿名下载。开始响应可能已消耗一次额度，取消后重新下载可能再次计次。取消须结束操作并清理临时文件，清理失败明确提示；若发布已经完成，则显示保存成功，避免把成功误报为取消。任何错误文案不直接回显原始能力链接或网络异常中的 URL。

共享发布器补齐发布前路径与已校验 FD 的设备/inode 一致性校验。替换临时文件路径的回归先复现失败，再验证拒绝发布。这防止已经发生的路径替换；同 UID 恶意并发在校验与 link 之间替换路径的完整原子防护、多卷/掉电边界仍属于 G10，不能宣称已完成。
