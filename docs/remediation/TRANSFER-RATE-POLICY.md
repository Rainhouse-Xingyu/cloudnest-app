# 上传下载速率策略

2026-10-23，G03 / PR #4。FILE-019 的请求参数、个人窗口和 Range 绕过已修复；G03 整体验收仍在进行。本批没有生产配置/数据库操作，也没有修改冻结 iOS。

## 生效规则

上传保留 upload_rate_kbps，所有下载（普通、版本、文件夹 ZIP、批量 ZIP、公开分享）保留 rate_kbps；历史参数名中的 kbps 实际单位仍为 **KiB/s（每秒 1,024 字节）**。缺省管理员普通上限为 2 MiB/s，显式服务端上限范围仍为 64–10,240 KiB/s。参数仅能降低上限，不能替代、提高或绕过服务端策略。请求值范围 1–10,240 KiB/s，空值、重复参数、零、负数、非法文本和溢出返回 400；不再静默修正为默认值。低速时客户端仍须将每片控制在既有四分钟期限内。

正常上限读取 upload_speed_limit_kbps / download_speed_limit_kbps；高峰时额外取 upload_peak_speed_limit_kbps / download_peak_speed_limit_kbps。高峰值缺失时沿用正常值，高峰值较大也不能提高正常上限。没有配置才使用默认值；存在但为空、非法/越界，或者数据库读取/锁失败，均返回 503，不能借请求参数绕过坏配置。

全局 peak_window_enabled/start/end 始终适用。个人 peak_window_*_user_<uid> 只能增加受限时段；关闭个人窗口或把它移到其他时间不能关闭管理员的全局窗口。两个窗口任一个命中就取 min(普通上限, 高峰上限, 可选请求值)。公开分享只使用全局策略，不使用匿名访问者或分享创建者的个人偏好。

时刻为服务器本地时区的 HH:MM（必须为四个数字和冒号），开始包含、结束不包含；跨午夜有效，起止相同表示全天。启用窗口但时间缺失/非法返回 503。个人窗口更新现在在一个设置事务中提交，第三字段失败也不会留下前两字段；服务层和 HTTP 输入均验证时刻。GET settings/rate-window 继续返回个人偏好/回落值，**它不是有效全局限速的完整快照**；关闭个人开关仍可能受到全局高峰约束。

每次传输在实际分片写入或下载打包/发送之前读取一次一致策略快照：沿用所有设置写入的策略排他锁，读取短事务持共享锁并一次获取相关设置，最长五秒；随后释放连接/锁再 IO。管理员批量更新和个人三字段更新均原子可见，不在传输期间持有数据库全局锁。已开始的传输沿用开始时的快照，跨窗口或修改配置从后续请求生效，不宣称逐字节动态重配。

## 实际 IO 与 HTTP

上传与下载共用单调时钟的累计字节调度器，计时使用整数运算且检查溢出；写入前做可取消等待。上传最多提前读入一个 32 KiB 缓冲，然后等待再写入候选，仍受入口体积、期限、准入和临时容量限制。下载在 ResponseWriter 处分成最多 16 KiB 写入并等待，不能通过 ReaderFrom/WriterTo 或整文件 copy 快速路径绕过；首次小响应也没有免费的整个文件突发。

下载统一使用标准 ServeContent 处理完整、单 Range、suffix、多 Range/multipart、If-Range、If-Modified-Since 及 416/304。所有实际响应体写入经过相同速率/取消检查，multipart 封装字节也计费，304 无响应体所以不等待体积预算。原读取租约仍包在实际底层写入，等待后再次检查租约，处理结束释放。

文件开始发送后出现错误，不向文件/Range 正文追加错误 JSON。抛出 net/http 的 ErrAbortHandler 终止响应；新的恢复中间件保留这个传输信号，普通 handler panic 仍隔离为 500，日志不打印请求头或 panic 内容。真实 TCP 测试注入第二次底层 Write 失败，客户端收到截断错误，收到的部分字节仍是原文件前缀且读取租约释放。客户端必须把正文读取失败视为未完成，不能只凭 200 状态确认下载成功。

## 证据与范围

修改前的真实 API 测试失败：64 KiB 上传在管理员 64 KiB/s 下用高 query 值仅约 146 ms；32 KiB 的普通/Range 下载约 10/22 ms。修改后对应上传至少约一秒、下载约半秒，且字节相同。这些小负载验证限速绕过，不是大文件吞吐/峰值内存基准。

新增十项真实集成覆盖上述绕过、全局高峰与个人关闭、六类下载坏配置拒绝、坏策略/歧义参数不登记上传候选、数据库读取失败不默认放行、真实 HTTP 写入失败截断、个人窗口最后字段故障回滚、并发管理员更新的完整快照，以及 suffix/multipart/If-Range/416/304 的字节/速率。单元测试另验证跨午夜边界、无首次突发与等待可取消、错误流不追加 JSON、恢复中间件及非法策略。完整结果见 [测试记录](TESTING.md)。

本协议上限是**每次传输**，没有承诺跨连接、跨用户或跨实例聚合带宽；全局带宽调度、连接公平性、传输中动态重配、慢下载连接期限/压力与 HTTP2 验证仍待 G03/G10。也不等同于下载强校验/安全恢复、完整客户端断点续传、ZIP/缓存磁盘预算；空文件已在后续批次实现（见 EMPTY-UPLOADS.md）。G04–G11 尚未完成。
