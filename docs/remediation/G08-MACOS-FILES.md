## 受管预览缓存与文件命令

新预览使用 `preview-cache-v1` 独立命名空间，共预留最多 512 MiB 文件内容、16 项，每项最多 256 MiB。请求入队前按文件列表中的大小预留，HTTP 表示大于预留时在写入前拒绝；较大文件仍可选择普通下载。预览使用原下载引擎的强身份、分段及整文件摘要校验。多个窗口各持有独立副本，正在准备或显示的副本不被容量压力淘汰；容量不足时提示关闭其他预览。

关闭/切换预览、关闭文件页、退出原账户或关闭队列时，会取消对应下载，等待工作任务退出，再删除该预览目录并释放预留。重复关闭共用同一清理任务，失败会保留预留并在下一次申请时重试。预览只在内存中显示进度，不进入持久传输历史；普通上传/下载的检查点恢复不变。队列关闭期间禁止调度新任务，避免清理时启动排队任务。

受管缓存根目录有固定格式标记。应用取得传输进程锁后，在启动恢复时清理该命名空间内的 UUID 目录，包括崩溃时尚未写入任务记录的副本。扫描先完整验证目录清单；遇到未知条目、替换符号链接或坏格式标记时停止预览准入并保留文件。旧版 `previews` 目录及其历史任务不由本机制自动删除，旧缓存的核对和迁移仍待处理。上述预算针对新版本生成的受管文件内容，不表示整个 Application Support 或系统磁盘占用均已受控。
