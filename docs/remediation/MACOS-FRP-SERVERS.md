# 原生 FRP 服务器登记

远程连接页增加“设备 / 服务器”分段。服务器列表调用已有 HTTPS API，固定每页 50 台，按 ID 游标替换页面；校验响应顺序、去重及下一游标，不在本地无限累积。翻页、离页取消旧请求，请求代号与身份检查阻止旧结果或旧 401 污染新页面/登录；读取失败清空旧元数据。

添加/编辑表单使用原生文本输入、开关、SecureField 和确认框。可编辑名称、TCP 范围、HTTP/HTTPS 端口及启用状态。主机和控制端口是既有服务端固定身份，修改请另建服务器。编辑绑定已读取 revision_id，PUT 提交 expected_revision_id；409 要求关闭、刷新并重新核对，不盲目覆盖或自动重试。保存不部署配置，也不修改 frps 进程；停用服务器不等于停止现有隧道。

编辑 token 显式区分保留（请求省略 token）、替换（输入新值）和清除（显式空值）。公开模型仅含 token_configured，不能读取旧 token。token 只用于本次请求，不写 journal/偏好/日志，离页或操作完成清除表单值；这不保证 Swift 字符串内存物理擦除。新建支持空认证，但必须显式关闭“使用认证 token”。旧配置引用原服务器版本，更换 token 后须另行生成和部署新配置。

保存前捕获并检查服务器/账户身份；参数先作范围、字节及控制字符校验，服务端仍执行完整策略校验。明确参数/权限/限流拒绝可纠正后再提交；网络错误、坏回执或结果不明禁止在同一表单重复提交，要求关闭并刷新核对。创建操作尚无持久幂等意图，不能把 FRP 命令 journal 的保障延伸到服务器创建；现有稳定端点唯一约束和更新 CAS 仍保留。
