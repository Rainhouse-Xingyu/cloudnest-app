# 文件变更与增量索引

索引的单位是 file_id，而不是共享 storage_id。不同文件即使物理去重，也有各自任务、代次和授权；不复制旧文件的向量行充当已完成的新索引。

## 已接入的事务入口

| 文件行为 | 索引行为 |
|---|---|
| 上传完成 | 文件、初始版本、配额、回执与第一代 queued 同事务；回执重放不重新入队 |
| 创建文件版本、恢复历史版本 | appendFileVersion 在更新当前引用与版本后强制生成下一代任务，和版本/配额/审计同事务；即使字节相同也记录新的索引代次 |
| 单文件、递归目录复制 | 每个复制出的普通文件建立独立第一代任务；目录不建立任务；失败使整个复制事务回滚 |
| 回收站恢复普通文件 | 恢复活动状态与下一代任务同事务，清除旧任务失败/租约；目录恢复不建立任务 |
| 改变扩展名 | 文件名、file_type 和下一代任务同事务；防止旧解析器按之前后缀发布结果 |
| 同扩展名改名、移动 | 无需重新提取正文；检索始终读取当前文件名、位置与 ACL |
| 放入回收站 | 搜索立即按活动状态排除；运行中的 worker 发布时检查源不可用；恢复再生成新代次 |
| 永久删除 | 文件删除事务同时清理 job/document/chunk；不能被旧 worker 重新发布 |

扩展名按大小写归一化比较。改名同步 file_type；超过数据库 varchar(50) 的未知长后缀使用空分类，保留完整合法文件名，不截断为另一种格式。当前解析仍由文件名后缀决定。改变后缀不会自动转换文件字节；不支持或不合法的格式由 worker 失败状态诊断。

所有入队依赖当前有效 storage 引用和规范 SHA-256 源身份；不能把未知历史对象猜测成有效源。入队失败使相关文件元数据事务失败，不能先返回文件操作成功再丢失调度。没有新增生产迁移，没有改写历史文件字节。

## 陈旧内容隔离

源 hash、generation、pipeline、租约 token 共同约束发布。更换源后旧 worker 无法提交；仅改变后缀或恢复相同源时，generation 隔离旧 worker。检索只读取活动文件的当前源/已完成代次，重建期间旧 document 可以保留用于事务替换，但不能继续作为当前正文结果。

这意味着短时间内文件仍可通过文件名搜索，而正文必须等新一代真正完成。此行为优先保证片段来自当前文件；尚未实现双版本索引无间断切换，不把旧正文冒充最新内容。

## 验证

`integration,aisearch` 新增四项：版本替换/还原及旧 worker、递归复制独立任务/权限/删除原件、扩展名与回收恢复、入队失败对改名/版本/复制/恢复的整体回滚。测试使用无向量的词法夹具验证协议，不能作为语义质量指标。

`integration,aimodel` 新增真实模型测试，通过公开文件 API 完成版本写入/恢复、复制、回收恢复、改为不支持后缀再恢复。每次成功处理检查实际 chunk 文本、1024 维归一化向量和当前状态；不支持格式必须明确 failed/unsupported_type。执行时长与完整回归见 [TESTING](TESTING.md)。

PDF/Office/OCR/视觉与 EXIF、完整标注评估仍未完成。历史未索引文件可按 [索引控制协议](AI-INDEX-CONTROL.md) 回填；已有文件的新合法变更已接入增量任务。
