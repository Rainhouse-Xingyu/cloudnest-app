# 零字节文件上传

2026-10-23，G03 / PR #4，关闭 FILE-018 的服务端空文件缺失。iOS 保持冻结；新 macOS 客户端仍待实现。本文不代表 G03 或全部项目验收完成。

## 协议

初始化必须明确包含数值 total_size=0；缺少该字段、null、负数仍返回 400。请求 DTO 使用非空指针区分“零”和“未提供”，JSON 字段/响应格式保持原样。空文件 total_chunks 必须为 0（可省略后归一化为 0），不能声称存在一个空分片。chunk_size 仍是正的协商尺寸，省略/0 时使用既有默认；为稳定恢复建议明确传入，例如 4096。负数及超过单片上限仍拒绝。

```json
{"filename":"empty.txt","parent_id":0,"total_size":0,"chunk_size":4096,"total_chunks":0}
```

保存 upload_id 后直接 POST upload/complete（原固定 parent_id），无需调用 upload/chunk。任何分片索引都返回 400，不生成分片候选。所有者、当前身份/业务权限、固定目录与参数、期限和取消约束不放宽；并发进行中的完成可 409/Retry-After，胜者提交后重试原 200 回执。

待完成时进度 status=0/progress=0，total_chunks/uploaded_count=0，两项索引列表为空；**没有待上传分片不代表文件已经发布**，客户端仍必须完成任务。完成后 status=1/progress=100，计数仍为 0，两列表仍为空。不能用“分片数为零”替代任务状态判断。

## 真实对象和记账

完成仍创建 Root/O_EXCL/随机路径的实际候选文件、取得 FD 锁、Sync 文件和父目录，Seal 核对 SHA-256（空字节的 e3b0c442…b855）与实际长度 0。临时登记至少收费 **1 字节**，仍受卷容量、statfs 余量、单任务/卷合并上限、租约/文件锁及审计约束；不是跳过登记或伪造下载成功。字节额度不等于完整文件系统块/inode 或数据库元数据成本。

逻辑用户配额预留和当前/历史/回收站对象计量均为实际 0 字节。在已使用量恰好等于配额时可创建空文件；非法计量/配置以及已有使用量超过降低后的配额仍拒绝新建，不借零字节跳过策略检查。只有 contract/chunk/transfer 协议均为 1、size/reserved=0、正且有界 chunk_size、total_chunks/uploaded_chunks=0 的完整形状被视为合法；NULL、旧协议、非零分片数等异常继续作为错误计量，取消仍可解除预留。

零字节对象沿用 Storage、初始版本 1、源验证、发布/完成回执/额度核销/审计同事务，未知提交继续保留候选。发布失败回滚且可重试；不会因为“空”就跳过物理校验。同摘要跨用户可去重，但对象存在不授予文件访问能力；删除一人的文件不能破坏另一个保留引用。

普通/历史/分享下载实际打开并验证文件，成功为真实空响应（Content-Length: 0）。版本恢复、复制、改名及永久删除沿用正常文件规则；回执仍只是原操作确认，改名/删除后不复活或重建文件。空任务有任何异常分片元数据时完成拒绝，不自动采用或删除这些路径，包括未完成的分片行。

## 升级与限制

本批不新增数据库字段，扩展既有版本 1 协议的严格零字节形状。必须整体停止旧写实例再更新代码；旧二进制将进行中的零预留视为非法，不能混跑或带着未完成空任务直接回滚后宣称无影响。已有旧分片/传输协议 0 任务仍拒绝自动认领，历史字节不被此功能清理。首次安装仍按现有显式迁移顺序；没有在真实库运行迁移。

空文件不消耗数据分片的网络传输，但仍需要磁盘目录、inode、数据库任务/文件/版本/审计记录；文件数/元数据数量配额尚未建立，不能把 0 字节解释成资源免费或已经有聚合资源治理。ZIP/缓存预算、真正暂停继续、下载恢复、大文件/内存/HTTP2、主机断电及 G04–G11 继续推进。

## 验证

新增十二项真实集成：原始发布/真实下载/完成重放，明确零值与规范分片声明，逻辑配额恰好耗尽，八请求竞争仅发布一次，所有者/固定形状/进度/改名回执，最小临时额度与容量不足，发布审计回滚，跨用户去重与删除后保留另一人下载，版本恢复/复制/分享及实际空文件/SHA，取消/过期/异常旧零任务，异常分片路径保留，以及坏配额/临时策略不能绕过。完整结果见 [测试记录](TESTING.md)。
