# 原生操作审计与有界 CSV

G09 在草稿 PR #10 接入真实审计 API；本批不修改数据库表、不删除历史日志、不合并 PR。原生侧栏提供本人记录、管理员全部账户、操作/状态精确筛选、可选起止时刻、详情展开、双向翻页与 CSV 保存。

## 查询范围与授权

旧 `GET /api/operation-logs` 的 page/limit 协议保留。新增 `cursor_mode=1` 使用固定 ID 上界 `snapshot_id`；`before_id` 向旧记录翻页，`after_id` 返回最近一页较新记录，不能同时使用。每个响应独立使用只读 repeatable-read 事务读取范围、数量和页面；不在请求间保留事务或服务端游标。新增记录不会进入原浏览范围，显式刷新重新取得上界。历史保留策略仍可能移除旧行，因此这不是不可变数据库快照。

本人条件始终在数据库作用域内应用。新协议普通账户 `all=1` 返回 403；旧协议保持原有仅返回本人记录的兼容行为。管理员只有显式选择全部账户才读取跨账户日志。操作、状态和时间筛选与导出共用作用域，当前文件访问权与历史审计查看权分别判断；历史详情不代表对应文件仍可访问。

原生固定每页 50 条、替换当前页，不累计历史页面；响应最多 256 KiB，并验证账户、范围、顺序、ID、游标及筛选结果。客户端选择本机时区，按秒归一化为 ISO 8601 时刻提交；列表按本机时区显示，CSV 明确为 UTC。取消、离页、权限拒绝及身份切换清理旧页面；导出捕获查询/上界/账户，在收到流和发布文件前再次核验，旧会话的迟到 401 不得撤销新登录。

## CSV 资源、完整性和本地发布

`GET /api/operation-logs/export` 保留原有八列：`id,user_id,file_id,action,status,detail,client_ip,create_time`。新请求传入同一 `snapshot_id` 和筛选。每次最多最新 5000 行、编码后 16 MiB；读取多一行判断截断，回执明确 rows/truncated/scope/actor/snapshot/UTC。最多生成 5001 行结果集前，先取得共享临时卷的归档活动准入，避免被拒绝的并发请求先分配大结果集；SQL 和编码受一分钟构建上下文约束。临时登记、增长预算、FD、封存摘要、限速、连接取消及释放沿用共享传输路径。

CSV 的引号/逗号/换行由标准 CSV 编码器处理。以公式字符开头的文本（包括前导空白、控制字符或 BOM）添加单引号，前导制表符/换行同样保护；原数据库内容保持不变。原八列的时间格式保留，现明确转换为 UTC。

原生使用隔离的已认证流，拒绝重定向、压缩表示或不匹配回执，校验强 ETag、Repr-Digest、完整长度和落盘 SHA-256。保存面板后再确认实际查询范围和目的地，先写 0600 私有临时文件，校验/fsync 后通过已有发布器避免覆盖同名文件。取消等待流与临时副本清理；已完成校验发布的文件优先于同时到来的取消。清理失败明确提示。没有自动重发、恢复 journal 或后台自动导出。

共享发布器的路径/FD 校验延续前批已有保证；同 UID 恶意并发 TOCTOU、多卷与突然掉电仍需 G10 专项，不能由普通私有目录验收推断全部完成。日志总量下的 COUNT 成本、全局查询/内存准入和聚合性能仍待 G10。

## 实测与失败记录

- 普通 Swift 最终 104 项注册，78 项实际通过、26 项条件跳过，0.125s（启用独立 Keychain 测试）；新六项覆盖坏响应、稳定分页、角色变化、导出损坏/重名、取消清理及旧会话流交接。URLProtocol 只用于客户端协议/竞态，不冒充真实网络证据。
- 最终审计专项 Go race + 实际 Swift/TLS/MySQL/Redis 15.277s：原生三角色 9.82s（管理员 6.04s、普通 1.72s、受限 1.63s），游标 0.29s、导出前准入 0.28s、有界 CSV/真实 TCP 释放 2.02s。5002 行只导出 5000 并标截断，公式/换行、旧上界、跨账户和旧协议均核对。真实慢流取消后活动句柄/容量释放，历史行保留。
- 原生真实网络覆盖管理员本人/全部、55 条翻页期间新增后刷新 56、普通账户 4 条及受限 403、真实 302 不跟随、线上字节损坏拒绝发布、16 KiB/s 慢流取消。服务端观察到取消后的父请求上下文结束且容量归零；未以仅客户端 task 状态判断释放。
- 最终 Universal Release、arm64/x86_64 和严格签名验证通过；相关 Go handler/service/contract/mysql 单元 race 通过（3.220/2.786/2.483/2.539s）。完整原生回归及其他最终检查结果另记 TESTING，按最终代码单独绑定。
- [真实双账户 GUI 报告](MACOS-AUDIT-GUI-20261127.json) 绑定 65 个 App/Core 文件指纹：首次 55、下一页 5、上一页不变、刷新 56；管理员全部 61、failed 11；普通账户无全部开关且仅 4 条。实际本人 CSV 为 4888 字节，SHA-256 `8240681bf8db6397b95bc8dd123d9db5a292065230eb02aaef1e52102223cef2`；普通 CSV 为 354 字节，SHA-256 `485d211de6ffbb0a7eeed38e72bfd9e58e8eb5d23a4ae8399b9f0583e94f5410`。分别回读行数、账户与内容，均无临时残留。浅深色观察、正常退出与服务结束通过（fixture 198.36s / Go 200.113s，端口关闭）。API 种子/旁路观测与真实 GUI 动作分开记录。

首次真实联调失败如实保留：测试将 302 拒绝误期望为 unavailable，实际为 invalidResponse，未跟随重定向。另一失败来自上一轮导出进度未清零：测试误判新慢导出已在途、过早取消，实际随后完整保存。先加断言复现进度残留，再修正新查询清零，并要求测试看到当前 exporting 且 received>0 才取消，仍保持三秒释放期限；最终真实慢流取消通过。早期 Swift 测试编译中的局部名称遮蔽也已修正，未修改产品接口掩盖错误。

GUI 当前观察为 900×590 点；角落拖动未改变尺寸，不据此宣称最小窗口通过。说明文字在当前宽度有截断，完整文字可从 AX 读取；文字缩放、完整 VoiceOver、最小窗口与多显示器继续列入 G10。设置前批 8236cee 精确双平台原生和完整后端 CI 已全通过，原 macOS 26 429 与扫描 PDF 首轮失败记录保持；本批远端 CI 发布后核对。
