# 原生 FRP 映射管理

远程连接的设备详情「映射」页提供添加、编辑和确认移除。新映射选择当前账户可见且启用的服务器，每页最多读取 50 项；编辑固定设备和服务器作用域。支持 TCP、HTTP、HTTPS、本地端口、启用状态及符合既有协议的远程端口分配。HTTPS 使用 SNI 透传，本地服务仍须提供有效 TLS，不在此签发证书。

正值服务器作用域的 HTTP/S 映射保留 `remote_port=0`，域名由后端规范化；TCP 可在新建或 HTTP/S 转 TCP 时按服务器当前策略自动分配。现有 TCP 编辑须提供明确远程端口。旧全局记录仍可编辑，HTTP/S 继续保留原协议要求的正值远程端口；不从原生界面创建新的零作用域记录。服务器端范围、禁用、归属、资源账本及唯一约束仍为最终判断，不将上次读取的策略当作保存保证。

## 并发与身份

`PUT /api/frp/mappings/:id` 新增可选 `expected` 对象，字段为 `device_id/server_id/local_port/remote_port/domain/status`。后端在原有池、设备和映射锁及归属复核后比较全部已读内容，不匹配返回 409，且不写入或追加成功审计。旧调用不带该对象时维持原语义，不需要数据库迁移。该保护比较内容，不提供跨多次修改又恢复原值的版本号保证。

原生编辑提交原始快照，不能用另一设备或服务器的选择覆盖其绑定；409 后锁定当前表单，关闭并刷新后再核对。客户端先校验端口、大小和控制字符，并核验成功回执的资源 ID、作用域、实际分配端口、规范化域名及启用状态。操作捕获服务器/账户身份，会话封装继续核验原 token，旧窗口不能借新登录发送操作。

参数、权限和限流拒绝允许纠正。网络或坏回执不视作保存失败可直接重发：当前表单停止重复提交，要求关闭并刷新列表。移除确认显示设备、映射 ID、作用域及历史保留，并限制同一详情窗口重复请求。映射创建/移除尚无持久幂等意图，不能套用[远程命令 journal](MACOS-FRP-COMMANDS.md)的恢复保证；进程崩溃、丢回执和再次打开后的完整故障矩阵仍属 G10。

## 配置与运行保留

映射保存或移除只改变资料，不会生成部署命令、停止现有隧道或释放运行占用。配置历史仍保留，须另行[生成并确认部署](MACOS-FRP-CONFIGS.md)。普通停止也不表示删除历史或释放资源。运行页显示采样配置 ID，需结合采样时间、逐条注册状态和实际请求判断，不能仅以命令 ACK 代替新心跳。
