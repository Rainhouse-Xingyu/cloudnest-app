# G06 协作权限

空间所有者可以新增、改派或移除普通成员和空间管理员。空间管理员只能管理 member、viewer、editor。空间所有者身份由 workspace.owner_id 确定，成员接口不能转让所有权。viewer、editor 和旧版 member 可以查看所在空间的成员列表。站点管理员使用同样的空间成员规则。

成员写入先锁定空间记录，再复核操作者和目标角色。创建空间时，空间、所有者成员记录和审计一次提交。新增、改派、移除成员也与审计同事务提交。

只有文件所有者可以授予或撤销文件协作者权限。已有 write 授权继续用于文件内容操作。若历史上为同一人保留了多条授权，新的授予或降级操作更新全部匹配记录，撤销删除全部匹配授权。授权变更和审计使用同一事务。

当前文件入口仍按文件所有者和显式授权判断读写。空间成员角色到文件 CRUD 的继承尚待实现和验证。旧空间、成员和文件授权记录不需迁移。
