## 3. 迁移策略

- 将 AI 模块核心业务逻辑下沉到 `AIService`，包括：
  - OCR 流程（文件可读性校验、EXIF 读取、Ollama 调用、元数据写入、任务写入）
  - 智能搜索与自然语言检索计划解析
  - 文档摘要（多格式文本提取与摘要落库）
  - 助手问答与配置项自动修改
- `AIHandler` 保留职责：请求参数校验、鉴权判断（管理员限制）、错误映射、响应结构组装。

## 4. 功能不变性声明

本次迁移保持以下不变：

- 路由与 HTTP 方法不变
- 返回结构不变（`item`、`items`、`pagination`、`nl_plan` 字段保持兼容）
- 关键错误语义保持兼容（如 `permission denied`、`file not found`、`ollama call failed`、`save ai metadata failed`、`admin only`）
- OCR、摘要、NL 检索、设置写入的既有业务规则与日志行为保持一致
